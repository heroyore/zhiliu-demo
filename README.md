# 智流工作台

访问：https://heroyore.github.io/zhiliu-demo/

静态体验版，可免登录使用。审批、任务、合同草稿、客户、会议、收支和报销等数据保存在当前浏览器，不会同步给其他人。支持 JSON 备份恢复与日常工作 CSV 导出。报销处理为本地手动登记，不发起转账，也不代表多人权限审批。

## 本次改进

- 报销提交、通过/拒绝、重新提交、登记已报销；记录处理历史。
- 登记报销自动生成关联支出，阻止重复记账和修改已审批金额。
- 客户、会议、收支、报销支持搜索、状态筛选及 CSV 导出。
- 全局搜索覆盖客户、会议、收支和报销，搜索结果可用键盘操作。
- 保存失败不会伪装成功；损坏数据保留并提供原始副本导出。
- 根目录链接自动进入工作台，原来的 `/dist/` 地址仍可使用。

## 开发验证

```sh
python -m http.server 8086 --bind 127.0.0.1 --directory dist
node --test tests/workflows.test.cjs
```

浏览器打开 `http://127.0.0.1:8086/`。测试使用独立内存数据，不读写用户业务数据库。网页验证应使用本地预览，避免往公开站点写入测试内容。

## 更新发布

修改后先运行上述检查，再提交并推送到 `main`。当前 GitHub Pages 从 `main` 根目录部署；推送后检查 Pages 构建成功，并核对线上文件与本次提交一致。只发布 `dist/`、入口、文档和测试，不上传本地数据库、账号、备份或密钥。公开版本只有浏览器本地数据；多人共享需要另行部署服务器。

## 会议跟进

会议保存后可以填写跟进事项、负责人和截止日期并生成任务。每场会议可生成一项关联任务，重复提交会返回已有任务。可在任务详情推进状态，并返回来源会议查看记录。已有任务的会议保留来源信息。所有记录仍只保存在当前浏览器，备份导出包含会议与任务的关联。
